# PlantBot Firmware v1.3.0-gamma

**Pre-release / Gamma** — GitHub als Pre-release veröffentlichen.  
**Basis:** Änderungen seit **[v1.3.0-beta](v1.3.0-beta.md)** (28. August 2026).  
**OTA-Kanal:** `pre-release:v1.3.0-gamma` in `version.txt` (Checkbox „Pre-Releases (Beta)“ in `/config` aktiv).  
**Home Assistant:** empfohlen **[plantbot-HA v1.2.10-gamma](https://github.com/fabibo89/plantbot-HA/releases)** (Update-Info per MQTT-Status).

---

## Highlights

- **Firmware-Update-Check per MQTT:** `latest_version` und `update_needed` werden im Topic `plantbot/{ip}/status` mitgeschickt — HA erkennt verfügbare Updates ohne HTTP-`/status`-Polling.
- **Periodischer Check:** einmal beim Boot (wie bisher) plus alle **6 h** im Idle (nicht während Gießen/OTA); danach sofort Status-Publish.

---

## Änderungen im Detail

### MQTT `…/status` (neu seit Beta)

| Feld | Bedeutung |
|------|-----------|
| `latest_version` | Neueste Version aus `version.txt` (Kanal `release:` / `pre-release:`) |
| `update_needed` | `1` wenn Update verfügbar, sonst `0` |

Bestehende Status-Felder aus Beta (`flow`, `last_volume_ml`, `water_runtime`, `watering`, `last_reset_reason`, …) unverändert.

### Verhalten

- `GithubUpdater::checkForUpdates()` beim Boot und alle 6 h Idle
- Pre-Release-Kanal weiter über Checkbox `preRelease` / `version.txt`
- Keine SPIFFS-Änderungen in diesem Release

---

## Zugehörige Home Assistant (v1.2.10-gamma)

→ **[plantbot-HA v1.2.10-gamma](https://github.com/fabibo89/plantbot-HA/releases)**

- übernimmt `latest_version` / `update_needed` aus MQTT-Status
- Update-Entity zeigt „Update verfügbar“, wenn die Station das meldet

---

## Upgrade von v1.3.0-beta

1. In `/config` „Pre-Releases (Beta)“ aktiv lassen.
2. Firmware **v1.3.0-gamma** per OTA oder USB flashen.
3. **SPIFFS:** nicht nötig, wenn bereits von Alpha/Beta aktuell.
4. HA auf **v1.2.10-gamma** aktualisieren und Integration **neu laden**.
5. MQTT prüfen: `…/status` enthält `latest_version` und `update_needed`.

---

## Bekannte Hinweise

- Update-Check läuft nicht während Gießen oder OTA-Install.
- Stations-Config `version` muss zur installierten Firmware passen (nicht `v0.0.0`), sonst ist der Vergleich unzuverlässig.
- Beta-/Alpha-Hinweise gelten weiter — siehe [v1.3.0-beta](v1.3.0-beta.md) / [v1.3.0-alpha](v1.3.0-alpha.md).
